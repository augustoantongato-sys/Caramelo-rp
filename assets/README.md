# Biblioteca de recursos

Pastas reservadas para ativos do jogo:

- `models/`: modelos 3D originais/licenciados (`.glb` recomendado).
- `materials/`: texturas e materiais (`.png`, `.jpg`, `.webp`).
- `audio/`: efeitos e música originais/licenciados.
- `ui/`: ícones, fontes e elementos da interface.
- `references/`: referências de produção; não são importadas pelo jogo.

Antes de integrar um arquivo, conferir escala, pivô, colisão, número de polígonos, tamanho de textura e licença. Para Android, preferir malhas otimizadas, texturas comprimidas e materiais compartilhados.
